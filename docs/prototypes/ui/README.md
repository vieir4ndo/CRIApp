# Prototipos UI - CRIApp

Estos prototipos se generaron como apoyo al backlog nuevo, respetando la direccion visual actual de la app Android:

- gradientes azul/morado,
- tarjetas redondeadas,
- botones azules,
- mensajes de error en rojo,
- estructura de menu por bloques.
